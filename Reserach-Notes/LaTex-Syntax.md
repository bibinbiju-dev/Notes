# Syntax

**Spaces** --> LaTex normalises spaces in its input files so that whitespace character are treated uniformly as space.

**Reserved characters** --> there are some reserved characters in LaTex. these characters have either special meaning in LaTex or are unavailable in all the fonts.
if we use this characters in LaTex it won't print anything but will have unexpected behaviours.

```tex
\# \$ \^{} \& \_ \{ \} \~{} \textbackslash{}
```
