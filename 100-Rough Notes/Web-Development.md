# Web Development

Web Development is the process of creating and maintaining websites and web applications.It involves designing user interfaces,processing data,and connecting different components.

- it has 3 main areas
  - **Front-End**
  - **Back-End**
  - **Data Base**

There are some fundamental concepts in web development
[[How-Web-Works]]
[[Basic-Web-Concepts]]

## Front-End

Front-End development focuses on creating visual elements and interactive features that users see and interact with in their browsers.
[[Front-End]]

## Back-End

Back-End development focuses on server-side technologies that process requests, manage data, and handle application logic.
[[Back-End]]

## Data-Base

A database stores and manages websites data, such as user information,products, and transactions.
