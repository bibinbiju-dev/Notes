# Session-Storage

Session storage allows developers to **store and retrieve data in the browser** for a single session.
The data stored here is:

- **temporary**
- **cleared automatically when the tab or window is closed**
- **accessible only within the same tab and same origin (same domain, protocol, and port)**

- **it is read-only**
- **it is ideal for holding temporary data**
