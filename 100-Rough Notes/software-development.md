# Software Development

## Models

### SDLC

it stands for software development life-cycle. it includes many stages like requirement analysis , planing, design, development etc. it is also know as water-fall model.

#### Steps

1. Planning & Requirement analysis : what does the client actually need and time,tech,stack should be used.
2. Design : UI/UX design/ technical design.
3. Development : coding starts using mearn.
4. Testing : need to test the each module developed by developers.
5. Deployment : tested application able to used by multiple users.
6. Maintanence : getting feed backs and rectify it.
