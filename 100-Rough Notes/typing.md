## why does configuration break ?

there are three common reasons:

1. an option is deprecated or removed. a plugin changes its API, so an old option stops working.
2. the configuration structure changes. for example, an extension previously leaded in one place is now configured differently.
3. your plugin manger or distribution changes its conventions. lazyvim may modify how it expects you to override defaults, even if the underlying plugin still works.

your telescope example illustrates the distinction: layout_strategy = "vertical" is an established option, while preview.treesitter= true is not documented telescope preview option. that kind of issues doesn't necessarily mean the syntax recently changed; sometimes an option was simply invalid from the beginning.
