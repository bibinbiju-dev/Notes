## js fundamentals

what is js

it is a high level programming language used to make website interactive. it can manipulate HTML and CSS handle user events, communicates with APIs , and run on servers using environments like Node.js.

what are the difference between js,html,and css

- html defines the structure of a webpage.
- css controls it's appearance and layout.
- js adds behavior and interactivity.
