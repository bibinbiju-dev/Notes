# vim

What is vim ?
It is a power-full text editor that follows a different editing technique compare to other editors like vs-code and other ides. In vim there modes like normal mode insert mode command mode etc, where most of the time we will be generally in the normal mode.

## modes

- insert mode.
- normal mode.
- visual mode.
- command mode.

### Insert mode

i : enter insert mode **insert before cursor**
a : enter insert mode **insert after the cursor**
o : enter insert mode **open a new line below the current line and enter insert mode**

_there are also capital letters for each of the above command_

I : enter insert mode **enters insert mode at the beginning of the line no matter where the cursor is**

A : enter insert mode **enters insert mode at the end of the line**

O : enters insert mode **open a new line above the current line and enters the insert mode**

## vim vertical motion

j: moves down
k: moves up
h: moves left
l: moves right

## vim motion horizontal

w - jump forwards to the start of a word.
e - jump forwards to the end of a word.
b - jump backwards to the start of a word.
