## Functional Component

a functional component is simply a js function that returns JSX.
we can use hooks such as usestate and useffect to give the component state and react features. it is primarily used for representing ui and rendering component.

we use functional components more often than class components because it is simpler , it is just a js function where as a class component needs more structure.

## Class Component

class component uses a js class and extends react.component.

differences between props and state

props (properties) are values passed from a parent component to a child component.
state is data that belongs to the component and can be changed over time.

useMemo : is a react hook that memorizes the result of a calculation and only recomputes it when its dependency array changes, helping avoid expensive recalculations and unnecessary re-renders.

html2canvas is a javascript library that captures html elements and renders them as images inside a `<canvas></canvas>` element directly in the browser.
