# Front-End

Front-End development focuses on creating the visual elements and interactive features that users see and interact with in their browsers.

- [[HTML]] is the language that defines the structure and content of web pages using elements, tags, and attributes.

- [[CSS]] styles web pages by controlling colors,fonts,layouts, and responsive designs.
- [[JavaScript]] makes web pages interactive through features such as buttons, animations,and form validation.
